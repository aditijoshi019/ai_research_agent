# Evaluation Notes

For every test, record:
- Query
- Expected dynamic requirements
- Expected sources/evidence
- Actual output
- Requirement coverage (met / partial / missing)
- Citation validity
- Source relevance (1-5)
- Factual support (1-5)
- Confidence calibration
- Latency and errors
- What worked / what failed
- Improvement

## Test queries
1. Compare three open-source vector databases for a startup building RAG products.
2. Find five Indian B2B SaaS startups in HR tech and summarize their positioning.
3. Explain pros and cons of multi-agent architecture for customer support automation.
4. Compare approaches to adding memory in an AI support agent.
5. Research a narrow topic with limited public evidence and verify that the agent reports uncertainty.
